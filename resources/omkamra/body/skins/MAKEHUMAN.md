# MakeHuman skin asset

`makehuman.glb` is generated on demand from the MakeHuman project's default
assets:

- `base.obj` — the base mesh: the naked body plus modelling helpers;
- `default.mhskel` — the default skeleton, 163 bones including fingers and toes;
- `default_weights.mhw` — the default skin weights.

The OBJ bundles its helpers in named groups. The converter keeps `body`,
`helper-l-eye` and `helper-r-eye` and drops the rest: `helper-skirt`,
`helper-tights`, `helper-hair`, teeth, tongue, eyelashes, genital and the
`joint-*` markers are MakeHuman's modelling aids, not parts of a character.
The result is a clean, naked, bald body of 14,677 vertices and 27,036 triangles.
The pack supplies no hair, so the head is bald; the skin's painted features
make the face readable, and a hair asset can be added later the same way as the
texture.
MakeHuman does not ship a finished character file: characters are generated by
applying targets in MakeHuman (or MPFB in Blender), which is outside this
repository. Hair and clothing are separate asset packs; the skin texture below
is taken from one of them.

## Skin texture

The body's diffuse map is `toigo_light_skin_female_bronze` from the CC0
`skins01` asset pack, which paints skin tone, and the face's eyes, brows, nose
and lips onto the base mesh's UV layout.

- Author: MargaretToigo
- License: CC0
- Source: <http://www.makehumancommunity.org/node/1133>
- Diffuse map: <http://files.makehumancommunity.org/sites/default/files/skins/1968/588659257/young_lightskinned_female_diffuse_Bronze.png>

The source is a 2048x2048 PNG of about 4 MB. glTF embeds images verbatim, so
the converter resamples the map to 1024x1024 and encodes it as a JPEG on a
white background. The prepared map is not committed; like the GLB it is a
cached reference. The GLB embeds it through `images`/`textures`/`samplers` and
the material's `baseColorTexture`.

The diffuse map is CC0 like the rest, so the whole asset stays CC0.

Source: <https://github.com/makehumancommunity/makehuman/tree/master/makehuman/data>
(the files are downloaded on demand).

## Cached assets

Neither `makehuman.glb` nor the prepared diffuse map is committed to Git. Both
are cached references (`omkamra.dev.cached-refs`):

- `omkamra.body.skins.makehuman.build/texture` — the prepared 1024x1024 JPEG;
- `omkamra.body.skins.makehuman.build/glb` — the skinned GLB.

Dereferencing a reference downloads the CC0 sources, produces the artifact and
persists it below `.cache/refs/omkamra/body/skins/` (the keyword namespace is
expanded to directories). The development asset server dereferences `glb` on
the first request for `/omkamra/body/dev/assets/makehuman`, so the examples page
triggers production lazily. Cache contents are ignored by Git.

## Regenerating

```clojure
;; in the project JVM: load the cached artifacts, or force a rebuild
(require '[omkamra.body.skins.makehuman.build :as build]
         '[omkamra.dev.cached-refs :as cached-refs])
(alength @build/texture)
(alength @build/glb)
(cached-refs/refresh! build/glb)
```

```sh
# or warm the cache from a shell
clojure -M -m omkamra.body.skins.makehuman.build
```

To use a different CC0 or CC-BY diffuse map, change the `diffuse.png` entry in
`omkamra.body.skins.makehuman.build/sources` before producing the texture.

The converter downloads the CC0 sources on demand, converts decimetres to
metres, moves the body so the feet rest on `y = 0`, splits vertices at UV seams,
computes smooth vertex normals, keeps the four strongest influences per vertex,
flips the texture V axis from OBJ's bottom-left origin to glTF's top-left
origin, and writes a single skinned GLB with the skeleton's rest pose, inverse
bind matrices and the embedded skin texture. It is plain Clojure and needs no Blender and no third-party tools.

Conventions of the generated asset (matching `omkamra.body.skeleton`): metres,
Y up, the body faces +Z, the body's left is +X.
